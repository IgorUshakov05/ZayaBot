# Документация API для обработки заявок

## Общая информация

API предназначено для обработки входящих заявок с веб-форм. Поддерживает валидацию данных, загрузку файлов, проверку тарифных планов и автоматическую рассылку уведомлений в Telegram.

## Базовый URL
```
https://zayabot.huntteam.ru/api/v1
```

## Эндпоинты

### Отправка заявки

**POST** `/request?domain=your_domain`

Отправляет заявку от пользователя, валидирует данные, проверяет тарифный план и рассылает уведомления ответственным пользователям.

#### Параметры запроса

**Query параметры:**
- `domain` (обязательный) - домен отправителя для валидации источника

**Headers:**
- `x-api-key` (обязательный) - API ключ для аутентификации. Он выдается при регистрации компании через телеграм бота @zaya_crm_bot
- `Origin` - домен источника запроса (автоматически)
- `Content-Type: multipart/form-data` - для загрузки файлов

#### Тело запроса (FormData)

Все поля являются опциональными:

| Поле | Тип | Описание | Валидация |
|------|-----|-----------|-----------|
| `name` | string | Имя пользователя | Макс. 20 символов |
| `user_phone` | string | Телефон пользователя | Макс. 15 символов, только цифры, +, -, (), пробелы |
| `user_post` | string | Email пользователя | Должен быть корректным email |
| `user_company` | string | Название компании | Макс. 30 символов |
| `user_address` | string | Адрес пользователя | Макс. 50 символов |
| `message` | string | Текст сообщения | Макс. 1000 символов |
| `file` | File | Прикрепленный файл | Макс. 5 МБ |

#### Ответы

**Успех (201):**
```json
{
  "success": true,
  "message": "Успех!"
}
```

**Ошибки:**

- **400** - Ошибки валидации:
```json
{
  "success": false,
  "errors": [
    {
      "msg": "Сообщение об ошибке",
      "param": "имя_параметра",
      "location": "body"
    }
  ]
}
```

- **400** - Ошибки домена/API ключа:
```json
{
  "success": false,
  "message": "Скрытые источники"
}
```

```json
{
  "success": false,
  "message": "API ключа нет!"
}
```

```json
{
  "success": false,
  "message": "Не верный источник",
  "queryDomain": "example.com",
  "requestDomain": "another.com"
}
```

- **400** - Ошибка тарифа:
```json
{
  "success": false,
  "message": "Обновите тарифный план!"
}
```

- **500** - Ошибка сервера:
```json
{
  "success": false,
  "message": "Ошибка сервера"
}
```


### Особенности:

- **Тестовый режим**: Для тестовых компаний отправляются только тестовые уведомления
- **Тарифные планы**: Поддерживаются различные модели оплаты (за период/за заявку)
- **Баланс**: Автоматическая проверка и списание средств
- **Лимиты**: Проверка месячных лимитов заявок
- **Файлы**: Поддержка загрузки файлов до 5 МБ
- **Telegram интеграция**: Автоматическая рассылка уведомлений в Telegram

## Пример использования (клиентская часть)

```javascript
const formData = new FormData();
formData.append("name", "Иван Иванов");
formData.append("user_phone", "+7 (999) 123-45-67");
formData.append("user_post", "ivan@example.com");
formData.append("user_company", "Моя Компания");
formData.append("user_address", "г. Москва, ул. Ленина, д.1");
formData.append("message", "Это тестовое сообщение");
formData.append("file", fileInput.files[0]); 

const response = await fetch(
  `https://zayabot.huntteam.ru/api/v1/request?domain=your_domain`,
  {
    headers: {
      "x-api-key": "your_api_key_here",
    },
    method: "POST",
    body: formData,
  }
);

const result = await response.json();
console.log("Ответ сервера:", result);
```

## Примечания

- Все поля формы опциональны, но рекомендуется заполнять хотя бы контактные данные
- Валидация телефона допускает только цифры и основные символы форматирования
- Максимальный размер файла - 5 МБ
- Для работы API необходим корректный домен и API ключ
